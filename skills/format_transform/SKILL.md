# format-transform

## 1 概述

本技能用于生成并且调试python脚本文件。针对卫星遥测参数日志文件中的格式不统一、样式各异的问题，以标准化的日志格式为参考，针对要处理的日志文件，生成日志格式转换python脚本，将不同格式的日志按照统一的格式进行整理。

如果要处理的日志文件与标准化日志的格式差异过大，经过判断，不是同一类设备或者分系统的日志，请直接告诉用户相关情况。

## 2 主要流程

### 2.1 日志格式转换脚本生成流程

1. 阅读标准化日志格式，并且查阅reference文件夹下的参考脚本代码和标准化日志文件，重点关注标准化日志文件的标题表头和日志文件中数据的类型（type)；

2. 读取用户提供的日志文件，解析其文件标题表头和文件前几行数据，并且与标准化日志的表头进行比较。如果目标日志文件与标准化日志格式差异过大，经过判断，不是同一类设备或分系统的日志，直接结束流程，并向用户简述这种情况；

3. 对于日志文件的表头标题来说，以标准化日志文件的表头为标准，（1）若目标日志文件的表头与之含义相同但是名称不同，则统一转变为标准化日志文件的表头表述；（2）若目标日志的表头中有标准化日志文件中不存在的字段，则将多出的字段和数据统一合并为一列，列标题为"extra data"；（3）若目标日志中的表头与标准化日志文件的表头相比存在缺项，那么缺项的标题保留，数据置空。

4. 对于表格内数据来说，以标准化日志的数据格式和枚举值为参考，（1）若目标日志的数据格式与标准化日志不同，则按照标准化日志的格式进行改写，例如目标日志数据为数值量1,2,3，而标准化日志为正常模式、轨控模式、安全模式等，则按照相关标准对于数据进行映射；（2）若目标日志的数据的枚举值与标准化日志不同，则按照标准化日志的枚举值进行映射。

5. 请针对目标日志文件，编写基于python语言的转换脚本，并利用用户提供的目标日志文件进行测试，验证其是否可以转换成功。对于正常运行情况，请将运行结果传递出来，对于异常运行情况，请把具体的运行异常、问题传递出来。

6. 请撰写一个使用说明文件，放在scripts文件夹下，说明使用python脚本进行日志格式转换的操作流程。

### 2.2 日志格式转换脚本故障排查流程

1. 当日志格式转换发生错误时，请根据系统传递出来的具体的异常情况进行脚本修正与重新测试。

2. 使用grep工具快速检索到发生异常的代码段，并且视情对于选定的代码段或整体脚本进行修改。

3. 在进行脚本修改时，请确保修改的内容尽可能少。

## 6 常见问题

### 6.1 对于过大的日志文件直接读取，导致上下文长度过长

解答：在读取文件时，一般情况下只读取前3行。在处理问题时，使用grep工具查找到出现问题的日志段落，并且有选择性的读取问题附近的数据。

### 6.2 在处理过程中，需要确保上下文尽可能简洁明确。

### 6.3 python脚本的应用方式

生成的python脚本是一种通用的工具脚本，用户调用的步骤如下：

cd skills/format_transform
python scripts/脚本名称.py --data 要转换的日志地址及名称

### 6.4 如果目标日志与标准化日志的表头差异过大怎么办？

解决方案：

1. 优先进行精准匹配，然后进行语义匹配，最后再进行模糊匹配，例如将“蓄电池A测点1”与“蓄电池1主份测温”相匹配。
2. 对于难以确定的字段，在理解数据含义后给出匹配建议并向用户确认，再执行后续转换。
