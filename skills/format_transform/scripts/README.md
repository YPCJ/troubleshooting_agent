# 日志格式转换脚本使用说明

## 介绍

本脚本旨在将卫星遥测参数日志文件转换为标准化的日志格式。它会读取指定目录下的CSV文件，按照预定义的标准格式对列标题进行重命名，并且将不符合标准格式的列归类到'extra data'列中。

## 使用方法

1. **确保环境**：请确保您的系统已安装Python（建议使用Python 3.8及以上版本）以及pandas库。可以通过运行`pip install pandas`来安装pandas。

2. **运行脚本**：在命令行工具中，转到包含此脚本的目录，然后运行如下命令：
   ```bash
   python log_format_converter.py
   ```

3. **查看结果**：脚本会在当前目录下创建一个名为`converted_logs`的文件夹，并在其中放置转换后的CSV文件。

## 注意事项

- 请勿更改脚本所在目录结构，否则可能会影响脚本正常工作。
- 当前脚本假定所有待处理的文件均位于`target`子目录下。如果需要处理其他位置的文件，请修改脚本中的相关路径。
