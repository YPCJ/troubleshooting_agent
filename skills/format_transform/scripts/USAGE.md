# 日志格式转换脚本使用说明

## 1 简介
本脚本 `convert_log.py` 用于将目标卫星遥测参数日志文件（例如 `PACK_12_0058_ss_...`）转换为标准化的日志格式。
由于目标日志的字段名称和数量与标准化格式不同，脚本内置了模糊匹配和规则映射引擎，能够自动识别并映射相关的遥测字段（如“蓄电池A测点1”映射为“蓄电池1主份测温”），同时将未匹配上的额外数据合并至新增的 `extra data` 列中（以JSON格式存储）。

## 2 环境要求
- Python 3.6+
- pandas

## 3 使用方法

### 3.1 命令行运行
在当前环境激活 Python 后，使用以下命令执行格式转换：
```bash
python scripts/convert_log.py --data <目标日志文件路径> [--output <输出文件路径>]
```

### 3.2 参数说明
- `--data`: 必须。指定要转换的目标日志文件路径（例如 `target/PACK_12_0058_ss_20250824_100794625.csv`）。
- `--output`: 可选。指定转换后输出的CSV文件路径。如果不指定，默认会在 `output` 目录下生成 `[原文件名]_converted.csv`。

### 3.3 运行示例
```bash
# 切换到 skills/format_transform 目录
cd skills/format_transform

# 执行转换
python scripts/convert_log.py --data target/PACK_12_0058_ss_20250824_100794625.csv
```
运行成功后，终端将打印出映射成功的列数以及生成的输出文件路径。

## 4 注意事项
- 对于与标准化日志格式差异过大的文件（例如不属于同一分系统的模拟量日志），本脚本可能会映射失败或产生大量未映射字段，请注意查阅终端的 `[INFO]` 提示。
- 转换后的时间列统一为 `yyyy-MM-dd hh:mm:ss.f` 格式。
